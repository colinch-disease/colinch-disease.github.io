이갈이와 턱 통증이 반복된다면 치아가 얼마나 닳았는지, 아침에 턱이 얼마나 뻐근한지, 잠자는 동안 어떤 소리를 냈는지를 7일 정도 적어 가는 편이 유리하다. 반대로 턱이 잠겨 입이 잘 벌어지지 않거나 얼굴이 붓고 심한 통증이 있으면 기록을 채우느라 진료를 미루지 않아야 한다. 이 글은 이갈이를 스스로 확정하는 방법이 아니라 치과나 의사에게 증상을 설명하기 위한 생활 관리 참고 자료다.

## 무엇을 기록해야 하나

이갈이는 본인이 자는 동안 알아차리기 어렵다. NHS는 치아가 닳거나 깨지는지, 아침 턱 근육이 뻐근한지, 동반자가 잠결에 이를 가는 소리를 들었는지 등을 진료 단서로 안내한다. 스트레스와 불안, 카페인·음주, 코골이나 수면무호흡 같은 수면 문제도 함께 적으면 턱 증상만 따로 볼 때보다 상담에 도움이 된다.

| 기록 항목 | 적는 방법 | 진료 때 의미 있는 단서 |
|---|---|---|
| 턱 통증 | 아침·저녁 0~10점, 위치와 지속 시간 | 한쪽만 아픈지, 씹을 때 심해지는지 |
| 이 악물기 | 낮에 이를 꽉 문 횟수와 상황 | 집중·운전·스트레스와의 관계 |
| 수면 관찰 | 이갈이 소리, 코골이, 숨이 막혀 깬 일 | 본인이 모르는 야간 증상 |
| 치아·입 | 시린 치아, 깨진 부분, 씹기 불편함 | 치아 마모나 손상 여부 |
| 생활 변수 | 카페인·음주 시각, 수면 시간, 스트레스 0~10점 | 증상이 심해진 날의 공통 조건 |

## 복사해서 쓰는 7일 기록 양식

아래 표는 메모 앱이나 종이에 그대로 옮겨도 된다. 통증 점수만 채우기보다 증상이 없었던 날도 `0`으로 적어야 비교가 쉽다.

| 날짜 | 아침 턱 통증(0~10) | 저녁 통증(0~10) | 씹기·입 벌리기 | 이 악물기 상황 | 수면 관찰 | 카페인·음주 | 메모 |
|---|---:|---:|---|---|---|---|---|
| 11/ |  |  | 불편/괜찮음 |  | 코골이·이갈이·모름 | 시각·양 |  |
| 11/ |  |  | 불편/괜찮음 |  | 코골이·이갈이·모름 | 시각·양 |  |
| 11/ |  |  | 불편/괜찮음 |  | 코골이·이갈이·모름 | 시각·양 |  |

동반자가 들은 소리나 아침에 발견한 치아·혀의 불편함은 추측과 사실을 나눠 적는다. 예를 들면 `본인 느낌: 아침에 턱이 뻐근함 / 동반자 관찰: 새벽에 2회 갈리는 소리`처럼 쓰면 된다. 사진이 필요하다고 임의로 판단하기보다, 깨진 치아나 잇몸 출혈이 있을 때 치과에 촬영 여부를 문의하는 편이 안전하다.

## 생활 중 줄여 볼 자극

턱이 아픈 날에는 껌, 질긴 음식, 크게 하품하기처럼 턱을 오래 쓰는 행동을 줄이고, 낮에 이를 맞물리고 있지 않은지 가볍게 확인한다. 카페인과 음주 시각, 수면 시간, 스트레스 점수를 함께 기록하되 특정 음식이나 보조제가 원인이라고 단정하지 않는다. 치과 장치나 약을 임의로 구매·중단하는 글이 아니며, 필요한 처치는 치아 상태와 턱관절 평가 뒤 의료진과 정해야 한다.

## 기록보다 진료가 먼저인 경우

| 상황 | 대응 |
|---|---|
| 턱이 잠겨 입을 거의 못 벌림 | 빠른 진료를 요청한다 |
| 얼굴·턱이 붓거나 열감, 심한 통증이 있음 | 치과 또는 의료기관에 바로 문의한다 |
| 치아가 깨졌거나 씹기 어려움 | 치과 진료를 미루지 않는다 |
| 가슴 통증, 숨참, 실신이 함께 있음 | 턱 문제로 단정하지 말고 응급 평가를 받는다 |

이갈이와 턱 통증은 스트레스만으로 설명되지 않을 수 있고, 코골이·숨 멎음 같은 수면 증상이 함께 있으면 별도 평가가 필요하다. 진단과 치료는 치과의사 또는 의사와 상담해야 한다.

짧게 정리하면, 7일 동안 아침·저녁 통증, 씹기와 입 벌리기, 낮의 악물기, 수면 관찰, 카페인·음주를 같은 표에 적으면 된다. 기록의 목적은 원인을 혼자 확정하는 것이 아니라, 진료실에서 빠뜨리기 쉬운 야간 증상과 생활 조건을 전달하는 데 있다.
