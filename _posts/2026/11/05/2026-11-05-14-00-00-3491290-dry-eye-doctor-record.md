눈이 뻑뻑하고 모래가 들어간 듯한 느낌이 반복된다면 안과 진료 전 7일 동안 **불편한 시간, 화면·바람 노출, 콘택트렌즈, 사용한 점안제와 복용약**을 같이 적는 편이 유리하다. 반대로 눈 통증이 심하거나 시력이 갑자기 달라지고, 빛을 보기 힘들거나 렌즈 착용 중 눈이 빨갛다면 기록을 채우기보다 빠르게 진료를 받아야 한다. 안구건조증의 진단과 치료는 의사와 상담해야 한다.

## 눈이 건조한 날에 같이 봐야 할 것

안구건조증은 단순히 물을 적게 마셔서 생기는 문제로만 볼 수 없다. 눈물이 부족하거나 눈물막이 빨리 증발할 때 생길 수 있고, 장시간 화면을 보거나 에어컨·난방 바람을 맞는 환경, 연기와 먼지, 콘택트렌즈, 일부 약물이 영향을 줄 수 있다. NEI는 따갑고 건조한 느낌, 이물감, 충혈, 눈부심, 흐릿한 시야를 대표 증상으로 설명한다.

| 기록 항목 | 적는 방법 | 진료에서 쓸모 있는 이유 |
|---|---|---|
| 불편감 | 오전·오후·밤 0~10점, 이물감·화끈거림·가려움 구분 | 증상의 시간대와 양상 비교 |
| 환경 | 화면 본 시간, 에어컨·선풍기·난방, 먼지·연기 | 눈물 증발을 늘릴 만한 상황 확인 |
| 렌즈 | 착용 시간, 뺀 시각, 착용 중 불편감 | 렌즈와 증상 시간 관계 확인 |
| 시야·통증 | 흐림, 눈부심, 통증, 충혈 여부 | 단순 건조감 외 평가가 필요한지 판단 |
| 약·점안 | 제품명, 사용 시각, 사용 뒤 변화 | 처방약·일반약·점안제 확인 |

이미지에서 봐야 할 점은 증상 점수 하나보다 **증상이 생긴 환경과 시각을 같은 줄에 남기는 것**이다.

## 복사해서 쓰는 7일 기록 양식

```text
날짜: ________   수면 시간: ____시간   콘택트렌즈: 착용 / 미착용

시간 | 불편감(0~10) | 증상(이물감·화끈거림·가려움·충혈·눈부심·흐림) | 직전 환경 | 점안·복용약
-----|--------------|----------------------------------------------------|------------|-------------
     |              |                                                    |            |
     |              |                                                    |            |
     |              |                                                    |            |

오늘의 환경: 화면 ____시간 / 에어컨·선풍기 ____시간 / 먼지·연기 노출 ______
렌즈 착용 시간: ____시 ~ ____시   뺀 뒤 증상: ______________________
한쪽만 심했는가: 예 / 아니오      통증 또는 시력 변화: ______________
오늘 새로 바꾼 화장품·세정제·약·점안제: ____________________________
```

정확한 분 단위가 기억나지 않으면 “점심 뒤 2시간쯤”, “화면을 오래 본 뒤”처럼 추정해서 적어도 된다. 매일 같은 척도를 쓰는 것이 중요하다. 점수는 진단 기준이 아니라 진료실에서 경과를 설명하기 위한 보조 자료다.

## 기록 기간에 할 수 있는 생활 관리

NHS는 화면을 오래 볼 때 눈을 쉬게 하고, 건조하거나 연기·먼지가 많은 환경을 피하며, 콘택트렌즈 착용자는 안경으로 쉬는 시간을 두는 방법을 안내한다. 실내 바람이 눈에 직접 닿지 않게 위치를 바꾸고, 화면을 보다가 의식적으로 눈을 자주 깜빡이는 것도 기록할 만한 생활 조정이다. 다만 기존에 처방받은 약은 눈이 건조하다고 임의로 중단하지 않는다.

기록 전후를 비교할 때는 한 번에 변수를 너무 많이 바꾸지 않는 편이 낫다. 예를 들어 3일은 화면 중간 휴식만 일정하게 지키고, 나머지 환경과 렌즈 시간은 평소대로 적으면 어떤 상황에서 불편감이 달라졌는지 설명하기 쉽다. 이것이 증상의 원인을 확정한다는 뜻은 아니다.

## 기록보다 진료를 우선해야 하는 경우

| 상황 | 대응 |
|---|---|
| 눈이 아프고 빨갛거나 렌즈 착용 중 충혈 | 당일 의료기관 또는 안과에 문의 |
| 시력 저하·번쩍임·시야 변화·심한 눈부심 | 응급 평가를 고려 |
| 몇 주간 관리해도 지속되거나 일상에 지장 | 안과 진료 예약 |
| 한쪽 눈만 유난히 심하거나 분비물이 동반 | 감염·각막 문제 등을 확인하기 위해 진료 |

안구건조감은 다른 눈 질환이나 전신 상태, 복용약과 함께 나타날 수 있다. 따라서 기록만으로 안구건조증을 확정하거나 점안제를 계속 바꾸지 말고, 7일 기록과 현재 사용하는 약·렌즈 정보를 진료실에 가져가는 것이 안전하다.

짧게 정리하면 **증상 점수, 환경, 렌즈, 점안·복용약, 시력·통증 변화**를 같은 날짜에 적으면 된다. 통증과 시력 변화가 있으면 기록 완성보다 진료가 우선이다.
