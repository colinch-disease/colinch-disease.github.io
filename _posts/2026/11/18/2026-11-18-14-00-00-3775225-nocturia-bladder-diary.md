밤에 소변 때문에 반복해서 깨고 낮에도 빈뇨·절박뇨가 이어진다면, 물을 무조건 줄이기보다 3일 배뇨일지를 들고 비뇨의학과 상담을 받는 편이 유리하다. 하루 이틀의 변화이고 수면·일상에 영향이 없다면 기록만으로 질환을 단정할 필요는 없다. 야간뇨는 수분 섭취, 수면, 약물, 당뇨 등 여러 요인이 얽힐 수 있어 진단과 치료는 의사와 상담해야 한다.

## 기록을 남기면 달라지는 점

“밤에 두세 번 간다”는 기억만으로는 진료 때 패턴을 설명하기 어렵다. NIDDK는 진료 전 2~3일 동안 마신 양과 시간, 소변 횟수·양, 강한 요의를 기록하면 원인을 좁히는 데 도움이 된다고 안내한다. NHS도 최소 3일 방광일지를 제시한다.

| 기록 항목 | 적는 예 | 진료에서 확인할 단서 |
|---|---|---|
| 마신 시간·종류·양 | 21:00 물 250mL | 늦은 시간 수분·카페인·알코올 |
| 배뇨 시간·대략적 양 | 02:10 중간 | 밤에 실제 소변량이 많은지 |
| 요의와 증상 | 급함, 따가움 없음 | 절박뇨·배뇨통·잔뇨감 |
| 수면과 생활 | 23:30 취침, 2회 각성 | 수면 분절과 낮 졸림 |

## 복사해서 쓰는 3일 양식

아래 표를 메모 앱이나 종이에 복사해 24시간 단위로 적는다. 소변량을 매번 재기 어렵다면 소량·중간·많음처럼 같은 기준을 쓴다.

| 날짜 | 시간 | 마신 것·양 | 소변량 | 요의 0~3 | 누출 | 증상·상황 |
|---|---|---|---|---:|---|---|
| 1일차 |  |  |  |  |  |  |
| 1일차 밤 |  |  |  |  |  |  |
| 2일차 |  |  |  |  |  |  |
| 2일차 밤 |  |  |  |  |  |  |
| 3일차 |  |  |  |  |  |  |

요의 점수는 0 없음, 1 조금 신경 쓰임, 2 서둘러야 함, 3 참기 어려움처럼 기준을 정해 일관되게 쓴다. 취침·기상 시간, 낮잠, 코골이나 숨참, 복용약 변경도 덧붙인다. 이 기록은 물을 제한하는 실험표가 아니다. 심장·콩팥 질환으로 수분 제한을 안내받았다면 섭취량을 임의로 바꾸지 않는다.

## 생활 관리와 진료 기준

늦은 시간의 카페인·알코올·많은 수분이 야간뇨와 겹치는지 기록으로 확인할 수 있다. 처방약이나 이뇨제 복용 시간은 임의로 바꾸지 않는다. 혈뇨, 열·옆구리 통증, 심한 배뇨통, 소변이 전혀 나오지 않는 증상이 있으면 기록을 기다리지 말고 의료기관에 연락한다. 갈증·다뇨·원인 모를 체중 변화, 다리 부종·숨참도 빠른 평가가 필요하다.

진료실에는 3일 표와 함께 “가장 힘든 증상 1개”, “밤에 깬 횟수”, “복용 중인 약과 시작·변경일”, “의사에게 묻고 싶은 질문”을 한 줄씩 적어 가져간다. 기록의 목적은 원인을 스스로 확정하는 것이 아니라, 생활 관리와 검사의 방향을 의료진과 함께 정하는 데 있다.

**짧은 요점**

- 야간뇨는 3일간 수분·배뇨·수면을 함께 기록한다.
- 물을 과도하게 줄이거나 약을 임의로 바꾸지 않는다.
- 혈뇨, 발열·옆구리 통증, 소변이 안 나오는 증상은 즉시 상담한다.

참고한 공식 자료는 [NIDDK 방광 조절 문제 진단](https://www.niddk.nih.gov/health-information/urologic-diseases/bladder-control-problems/diagnosis), [NHS 요실금 진단과 방광일지](https://www.nhs.uk/conditions/urinary-incontinence/diagnosis/), [Oxford Health 야간뇨 안내](https://oxfordhealth.nhs.uk/ababs/advice/understanding-nocturia/)다. 내용은 2026년 11월 18일 확인 기준이다.
