이 그림에서 볼 것은 ‘며칠에 한 번 갔는가’만 적는 것이 아니라 변 모양과 힘주기, 복용약을 같이 남기는 방식이다.

변비로 진료를 앞둔 사람에게는 완하제나 식품을 임의로 고르는 것보다 **최근 7일의 배변 패턴을 한 장으로 정리하는 일**이 유리하다. 반대로 피가 섞인 변, 계속되는 복통, 구토, 발열, 가스도 나오지 않는 상태, 이유 없는 체중 감소가 있으면 기록을 더 모으기보다 빠른 진료가 우선이다. 이 글은 변비를 스스로 진단하는 방법이 아니라 진료 준비용 생활 기록이다.

## 횟수만 적으면 놓치는 정보

미국 국립당뇨병·소화기·신장질환연구소(NIDDK)는 변비 증상으로 주 3회 미만의 배변, 단단하거나 덩어리진 변, 배변 시 통증, 다 본 것 같지 않은 느낌을 제시한다. 따라서 “월요일에 한 번”보다 아래 항목을 함께 적어야 의사가 패턴을 파악하기 쉽다.

| 기록 항목 | 적는 방법 | 진료 때 도움이 되는 이유 |
|---|---|---|
| 배변 시각·횟수 | 날짜와 대략적인 시각 | 아침에 몰리는지, 며칠씩 건너뛰는지 확인 |
| 변 모양 | 딱딱한 알갱이·덩어리·갈라진 소시지·무른 변 | 변의 단단함을 말로 설명하는 오차를 줄임 |
| 힘주기·잔변감 | 없음/조금/많음, 남은 느낌 유무 | 배변이 어려운 양상을 구분하는 단서 |
| 통증·복부팽만 | 0~10점과 지속 시간 | 배변 전후 변화와 심한 정도를 비교 |
| 약·보충제 | 이름, 복용 시각, 시작·중단일 | 변비에 영향을 줄 수 있는 요인을 확인 |

NIDDK가 공개한 Stool Diary도 배변 시각과 변 상태를 날짜별로 적도록 구성돼 있다. 변의 모양은 사진을 찍어 공유할 필요 없이, 기록지에 “작고 단단한 덩어리”처럼 본인이 이해할 말로 적어도 충분하다.

## 복사해서 쓰는 7일 기록 양식

아래 양식을 메모 앱이나 종이에 옮겨 아침·저녁 한 번씩 채운다. 식사 전체를 칼로리까지 계산하기보다 물 섭취가 평소와 달랐는지, 활동량이 줄었는지만 표시한다.

```text
날짜 | 배변 시각/횟수 | 변 모양 | 힘주기 0~3 | 잔변감 | 복통·팽만 0~10 | 물/활동 변화 | 약·보충제
     |                |         |             |        |                |              |
     |                |         |             |        |                |              |

최근 7일 요점
- 가장 오래 배변하지 못한 기간:
- 배변 뒤에도 남은 느낌이 있었던 날:
- 피·검은 변·구토·발열·체중 변화 여부:
- 새로 시작했거나 끊은 약·보충제:
- 진료에서 묻고 싶은 질문:
```

변비를 이유로 물이나 식이섬유를 갑자기 크게 늘리는 방식은 누구에게나 맞지 않는다. NIDDK도 복용약이나 보충제가 원인일 수 있다고 설명하므로, 변비약·철분·칼슘·진통제 등을 복용 중이라면 임의로 중단하지 말고 이름과 시작일을 그대로 적어 의료진에게 보여준다. 진단과 치료, 약 조절은 의사와 상담해야 한다.

혈변이나 검은 변, 지속적인 복통, 구토·발열, 가스가 전혀 나오지 않는 상태, 원인 모를 체중 감소가 있으면 생활 기록보다 즉시 의료기관의 평가가 우선이다. 증상이 반복되거나 자가 관리에도 계속되거나 대장·직장암 가족력이 있다면 기록 기간을 늘리기보다 진료를 예약한다.

짧게 정리하면 변비 진료 기록의 핵심은 **횟수·모양·힘주기·잔변감·복용약**을 같은 날짜에 묶는 것이다. 이 다섯 가지가 있어야 “변을 못 본다”는 표현이 실제 패턴으로 바뀐다.
